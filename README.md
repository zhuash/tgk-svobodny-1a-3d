# ТГК «Свободный 1а» — 3D massing (Three.js / WebGL)

Hard-dimensioned interactive 3D массинг здания ТГК «Свободный 1а» (Тверь, пер. Свободный 1).
Footprint 18 × 34 m, total height 9.5 m (1 эт 3.4 + 2 эт 2.9 + мансарда 3.2).
Self-contained: Three.js r160 and OrbitControls bundled locally under `libs/` — no external CDN.

Open the page, drag to orbit, wheel to zoom.
